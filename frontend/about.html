About Edusentia

A secure academic operations platform for modern schools.

Edusentia Enterprise connects school administration, educators, learners and families through one protected digital environment built for dependable academic operations.

Neon PostgreSQLCloudflare WorkersCloudflare R2GitHub Pages

Purpose

Edusentia is designed to reduce fragmented school administration, improve academic record integrity, strengthen accountability and provide dependable information for teaching, reporting and school decision-making.

Academic operations

The platform supports student and staff records, academic periods, assessment, report cards, attendance, certificates, transcripts, ID cards, analytics, licensing, backup and recovery, together with the operational workflows required by participating schools.

Security and continuity

Each tenant school operates in an isolated Neon PostgreSQL database. Privileged access is protected through role-based controls and multi-factor authentication, while Cloudflare Workers provide the application API and Cloudflare R2 provides protected object storage. Audit evidence, backup and recovery controls, release governance and health monitoring support operational continuity.

Developer and maintenance

Developed and maintained by Ephraim Owusu-Duah.

Deployment model

Edusentia Enterprise Neon Edition is cloud-first software. The public application is delivered through GitHub Pages, application services run on Cloudflare Workers, school databases are hosted on Neon PostgreSQL, and managed objects are stored in Cloudflare R2. Authoritative school data remains securely hosted rather than being copied onto individual devices.

The Neon Edition is an independent deployment of Edusentia. It does not depend on the Supabase runtime used by the separate reference edition.
