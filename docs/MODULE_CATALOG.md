# Module Catalog

## Active Neon Edition domains

The fresh Neon Edition preserves the active r42-v18/future-tenant business scope using native Neon, Worker API, and R2 implementations. Production provisioning is currently limited to Basic/JHS and Senior High School institutions.

- Authentication, MFA-ready account model, sessions, roles, and tenant memberships
- Institution configuration and tenant provisioning foundations
- Students, guardians, enrollment, staff, HR profiles, teachers, and headteachers
- Academic years, terms, classes, subjects, timetable, attendance, assessments, grading, reports, transcripts, and certificates
- SHS programme and subject structures where applicable
- Admissions, admission documents/offers, alumni, communications, notifications/outbox
- Discipline, welfare, student health, hostel and boarding operations
- Fees, invoices, receipts/payments, fee ledgers, holds, guardian contact, payroll, salary grades/rules, and staff loans
- Report templates, revisions/publication/corrections, ID cards, certificate batches/templates, and prospectus content
- Audit/security events, privacy/retention, imports, backups/restore staging, release verification, lifecycle events, and R2 object metadata
- Tenant licensing state backed by read-only platform plan/feature catalog metadata

## Retired historical domains

The certified future-tenant baseline treats these historical modules as retired, so they are not reintroduced into the fresh Neon runtime:

- Inventory
- Library
- Transport

Historical tertiary schema artifacts may remain as reference compatibility material, but tertiary institutions are not an active production provisioning model for the current future-school baseline.

Historical source/database artifacts from the Supabase edition are functional references only and are not runtime dependencies of this edition.
